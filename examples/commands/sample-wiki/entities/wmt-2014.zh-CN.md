# WMT 2014

## 概述

WMT 2014 是 [[summaries/attention-is-all-you-need]] 中用于评估 Transformer 英德与英法翻译的机器翻译基准年份。在论文中，它作为与先前最先进系统对比以及报告 BLEU 分数的标准参照点。

## 论文中的关键事实

- 论文在 **WMT 2014 英德** 与 **WMT 2014 英法** 任务上进行评估。
- 这些基准用于将 Transformer 与先前的序列到序列系统对比。
- Transformer 在英德任务上达到 **28.4 BLEU**，在英法任务上达到 **41.8 BLEU**。
- 论文报告，这些结果以远低于早期模型的训练成本取得。
